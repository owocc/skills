# 素材导出指南

> 主流程第 5 步「导出素材」的完整规则。导出前从头过一遍，尤其不要跳过背景组与自检清单。

## 1. 先确认尺寸倍率

素材解析开始前，先询问用户要什么尺寸的素材（`1x` 还是 `2x`），之后所有切图按该倍率导出，不再逐张追问。

## 2. 背景组整组导出（强制）

结论先行：**遇到表示“背景”的组，必须把整组作为单一素材导出，禁止导出组内子节点。**

### 为什么不能拆

背景经常不是一张图，而是**多张图片 + 蒙版 + 渐变拼接**的组：`Mask group` 互相重叠、渐变蒙版叠加在图片填充上、同一张原图（同 `imageHash`）以不同裁切 / 变换出现多次。拆成子节点单独导出会丢失组级合成关系——背景变成碎片、渐变蒙版丢失、多块裁切图无法重新拼合，还原必然失败。

**`scan_exportable_resources` 的子节点清单只代表“这些节点各自可导出”，不代表“应该单独导出”。是否原子导出，由下面的判定规则决定。**

### 判定规则（命中任一条件即视为背景组）

1. **组名命中背景语义**（不区分大小写、中英文都查）：
   - 中文：`背景`、`底图`、`底`、`场景`、`环境`、`光效`
   - 英文：`bg`、`background`、`backdrop`、`scene`、`wallpaper`
   - 组合变体：`bg_1`、`BG-home`、`background-image` 等前缀 / 后缀变体
2. **结构特征指向背景拼接**（组名未命中时兑底）：
   - 组内包含 `Mask group` / `蒙版` 子组，且子组之间 bounds 重叠；
   - 同一 `imageHash` 的图片以不同裁切 / 变换出现多次；
   - 子节点带渐变（`GRADIENT_*`）填充且透明度渐变（gradientStops 中有 alpha < 1），或 `blendMode` 非 `NORMAL`。

满足条件 1 的组**无条件整组导出**；仅满足条件 2 的组也整组导出（宁可多导一张背景，不可拆坏）。

### 执行顺序

1. **先看树，再扫描**：对目标画板先跑 `capture_layout`（`problemsOnly: false`），用判定规则标记所有背景组。
2. **背景组剔除出扫描清单**：扫描后，把位于背景组内部的子节点从导出清单中删除，改用背景组自身的节点 ID。
3. **整组导出**：`export_nodes` 传背景组的节点 ID，默认 PNG（带渐变 / 蒙版时禁用 SVG），倍率按用户确认的导出倍率。
4. **验收**：导出图与设计稿截图对比——若拆过组，两者会出现明显差异（缺渐变、断层）。
5. **命名落盘**：背景素材命名沿用组名（如 `bg-home.png`），放 `assets/` 目录，不做二次加工。

### 导出前自检（任一条不满足，禁止进入写码）

- [ ] 所有命中背景组名的 GROUP 都以组 ID 出现在 `export_nodes` 参数里？
- [ ] 导出清单里没有背景组的子孙节点 ID？
- [ ] 背景组带渐变 / 蒙版时用的是 PNG（而非 SVG）？
- [ ] 每个背景组的导出图与设计稿截图一致？

## 3. 头像类素材特殊处理

用户头像属于运行时数据，不属于页面素材，**不要导出头像内容**。检查设计稿和原项目是否已有 fallback 占位（默认头像）：有 → 用 fallback；没有 → 留空占位，并在素材清单中标记“待运行时填充”，写码时留出对应尺寸的容器。验证截图时同理（不比对头像内容，只比对占位位置与尺寸）。

## 4. 判重后归一存储

- 导出前：收集所有 IMAGE 填充的 `imageHash`，同 hash 的多个节点只导出一份；
- 下载后：对所有素材算内容哈希（md5），哈希相同的合并为一份；
- 合并后改用共享名（如 `ic-comment.svg`，不再 `post1-comment` / `post2-comment` 各存一份），只有内容确实不同的态（如 `like` / `liked`）才分开；
- 同一节点不重复存档：`export_nodes` 产物哈希一致时可直接作为对比基准，不再为每个背景组单独 `capture_screenshot` 存双份。

## 5. 素材清单（manifest）

导出完成后生成 `assets/manifest.md`，每行一个**唯一素材**，按下面约定格式落盘：

```markdown
# 素材清单 — <画板名>（<画板节点 ID>）

- 设计稿：<链接>｜画板：<宽>×<高>（@1x）｜导出倍率：@2x（按 @1x 尺寸显示）
- 命名约定：`bg-*` 整组背景（禁止裁切 / 拆用）；`ic-*` 图标；`avatar-*` 头像占位；其余按角色命名

| 文件 | 节点 ID（含复用者） | 设计稿原名 | 尺寸 / 位置 @1x | 类型 | 用途 |
|---|---|---|---|---|---|
| `bg-family-card.png` | `1:375` | 背景 | 362×221 @(20,142) | 整组背景 | 家族信息卡背景框 |

## 文本与字体

| 文本 | 颜色 / 字号 | 备注 |
|---|---|---|

## 图标字体字形

| 码点 | 字号 | 颜色 | 用途 |
|---|---|---|---|

## 待运行时填充

| 占位 | 容器尺寸 / 位置 | 说明 |
|---|---|---|
```

写码时照表取用；文本样式（颜色 / 字号）、图标字体码点、头像等运行时数据的占位都记录在这里。
