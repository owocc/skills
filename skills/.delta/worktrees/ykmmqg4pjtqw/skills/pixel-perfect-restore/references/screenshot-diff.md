# 截图对比细则

> 验证阶段的执行细则。验收标准与降级规则见 `SKILL.md` 第 6 步，这里是无头截图与量化验收的具体做法。

## 无头截图

- Chrome headless 最小窗口宽 500px：`--window-size=402` 无效，`#page` 会被居中偏移。做法：大窗（600×2000）截图，再按偏移（(600-402)/2=99px）裁剪出页面。
- 需等字体 / 图片加载完成再截：`--virtual-time-budget≥6000`。
- 实现结果截图与设计稿基准截图必须同尺寸后再比对，尺寸不一致时先裁剪 / 归一。

## 量化验收

- 验收方法：同尺寸逐行 / 逐列平均差扫描定位问题带 + 互相关找最优位移——先对齐结构（区块位置），再对齐字形（文字内容），比目测可靠。
- 结构性差异（区块位移、列差、缺素材、断层）必须清零；剩余差异只允许是字体渲染层面的噪声。

## 已知噪声（可接受，不要为消除它们无限迭代）

- 字体度量差异（设计稿 SF Pro vs 浏览器 SF NS）导致**换行点不同**：按设计稿断行位置硬断行 + 负字距（约 -0.55px）微调；每行内字形残差属字体渲染噪声。
- 背景图由 @2x 缩到 @1x 显示时，浏览器重采样与设计稿渲染有轻微软化差异，纹理密集区残差偏高属正常。
